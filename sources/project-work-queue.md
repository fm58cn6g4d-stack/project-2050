## Synchronization discipline

Before a new task, check remote branches/PRs and the relevant queue/source record. Concurrent writing uses separate branches and avoids simultaneous changes to shared files. A local saved artifact is a draft/source until its repository integration is explicit. A PR is proposed integration; only a reviewed merge updates the authoritative working branch.

This queue records known ownership and uncertainty. It does not claim that unobserved sessions are idle or that every listed task has been launched.
