# Project 2050

A country where people have security, time and real power, argued honestly and specified well enough to build. The working plan is [`charter/PLAN.md`](charter/PLAN.md); progress is on [`charter/PROGRESS.md`](charter/PROGRESS.md); how agents work is in [`charter/STANDARDS.md`](charter/STANDARDS.md).

| Folder | Holds |
| --- | --- |
| [`charter/`](charter/) | Plan, standards, progress board, outcomes record, decision log |
| [`dossiers/`](dossiers/) | Flagship, foundation and agenda dossiers |
| [`agenda/`](agenda/) | Every policy and option ID, with its level and status |
| [`library/`](library/) | Originals, the catalog and the name index |
| [`models/`](models/) | Models, data and checks |
| [`public/`](public/) | The site, briefs and organizing material |
| [`legacy/`](legacy/) | The project as of October 28, 2026, preserved read-only |

Run every check with `bash .github/scripts/run-checks.sh` (Python 3.10+ and Node.js).
