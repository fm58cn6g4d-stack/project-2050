# Library

Role: originals and their text versions, the catalog (`catalog.csv`, IDs like `SRC-0001`) and the generated name index, which maps every name a document has gone by to its one home. Status: `intake/2026-10-28/` holds Espen's October 28 uploads with checksums; the catalog and index are being built in stage A.

The repository is public. Open and public-domain material goes here in full; licensed or paywalled material is cited and briefly quoted, never committed.
