## PR #8 initial review notes

The prototype separates tax units and SPM units, labels full/delivered/enhanced scenarios and retains overlapping mechanisms. Those are useful choices. Static inspection identifies these next review gates:

- Credit changes use max(0, entitlement minus supplied current-law CTC). Negative changes cannot appear; this cannot support a claim about policy losers or whole-package D3 incidence. README discloses this limitation. Test or retain the restriction visibly.
- Mechanism flags/ordered attribution are calculated over all children, without conditioning on delivered poverty. They therefore are not counts explaining only residual poverty. Publish clearly labeled all-child flags and residual-poverty-conditioned tables before making residual claims.
- Full receipt cannot create an unrecorded care slot or unawarded voucher. Meal, housing, pre-K and other SPM effects are supplied from outside. It is not a demonstrated full-service counterfactual.
- Unit weights are replicated per child. Validate this against the chosen CPS person/SPM-unit weighting contract, including subgroup denominators. Test phaseout edges, identification branches, multi-tax-unit families, nonreceipt, zero weights, aggregation and service overlaps.
- Resolve the provisional statutory/tax integration, baseline/data preprocessing and benchmark validation before any national result; add uncertainty and scope checks before publication.

This is an initial static review, not executed validation, formal approval or a complete code audit. No PR comment or review was submitted.
