# CBO files uploaded by Espen, November 8, 2026

Role: original data files from the Congressional Budget Office, uploaded by Espen because www.cbo.gov blocks automated access (a bot check returns 403). Status: untriaged originals for the federal budget model (B2 data layer, B4 benchmarks); extract machine-readable tables into `models/data/cbo/` rather than editing these. CBO publications are works of the U.S. government and not subject to copyright. `SHA256SUMS` lists each file's checksum.

The leading number in each name is CBO's publication ID; the file names are otherwise CBO's own.
