# Dossiers

Role: one folder per flagship, foundation and started agenda topic. Status: current; the table below says where each dossier stands (the live detail is on the board, `charter/PROGRESS.md`).

Each dossier has the nine sections of `charter/PLAN.md` 3.3, an evidence register (`evidence.json`, IDs like `EV-HOU-001`), provisions (`provisions.json`, IDs like `HOU-4A.01`) and its design decisions. Foundations go in `dossiers/foundations/`; wave-two and wave-three topics in `dossiers/agenda/`.

Rules that more than one flagship depends on, such as what counts as income and which immigrants are eligible, are listed in `shared-rules.md` with their current working answer and owner dossier.
