# Memo H5: Whether the housing model is built in stage H

Role: decision memo for Espen, stage H step 1 (`../1-audit.md`, part 1.6). Status: **provisional, drafted November 25, 2026. Not decided.** Decided on its own, not as a package.

## The question

PLAN 3.4 lists a housing model ("assistance reach, rents, supply; new, small and evidence-based") among the core models. None exists: housing's cost is priced by hand in `dossiers/home/6-cost.md` (about $0.81 trillion over FY2030-39) and booked through the budget model's provision rows. Should stage H build it?

## The options

**A. Build a small model in stage H (recommended).**
- One Most capable session (H7): reproduce `6-cost.md`'s cost from its inputs, then add how many households the vouchers reach, the effect on rents where supply is short, and the supply response, each from the dossier's evidence register.
- *For:* completes PLAN's toolkit; the rent and supply questions are the ones housing's critics ask; a model would test the hand pricing. *Against:* one more session; a supply model is hard to do well, and a weak one invites attack.

**B. Defer it to housing's L4 work.**
- Build it when housing's priority pieces go to L4.
- *For:* stage H stays shorter; the model is built when its answers would change a design. *Against:* the toolkit is released without one of its seven models.

**C. Never: the dossier's hand pricing stands.**
- Drop it from PLAN 3.4's table (a charter change, tier 3).
- *For:* the least work. *Against:* housing is flagship 3, and its cost is the one flagship cost no model checks.

## Recommendation

**A**, limited to reach, rents and cost in stage H, with supply shown only as a range from the evidence, not a forecast.

## Consequences

- **A:** H7 runs alongside the other toolkit steps.
- **B:** stage H releases six models; housing's model goes on the board for L4.
- **C:** a tier-3 PR edits PLAN 3.4's table.
